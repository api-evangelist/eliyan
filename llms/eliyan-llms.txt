# Eliyan

> Eliyan Corporation is a fabless semiconductor company headquartered in Santa Clara, California
> that develops chiplet and chip-to-chip interconnect physical-layer (PHY) IP for multi-die and
> AI infrastructure systems. Eliyan licenses silicon IP and sells chiplets to semiconductor and
> hyperscale customers. It does NOT operate a public web API: there is no developer portal, no
> API documentation, and no machine-readable API contract (OpenAPI, GraphQL, AsyncAPI, gRPC,
> MCP, or A2A agent card). This file was generated by the API Evangelist enrichment pipeline
> from the company's public marketing site.

## Products

- [NuLink](https://eliyan.com/products/): Die-to-die (D2D) and die-to-memory (D2M) PHY IP core, using simultaneous bidirectional signaling; protocol-agnostic across UCIe, Bunch of Wires (BoW) and Eliyan's UMI.
- [NuLink-X](https://eliyan.com/products/): Chip-to-chip (C2C) PHY IP core for longer-reach connections between separately packaged devices across a PCB, at lower power than traditional SerDes.
- [NuLink-XD](https://eliyan.com/products/): Power-reach configurable 224G PAM4 SerDes for low-power electro-optical modules in AI scale-up fabrics.
- [NuGear](https://eliyan.com/products/): Chiplet products addressing memory and I/O bandwidth limits in high-performance systems.
- [UMI](https://eliyan.com/technology/): Eliyan's own universal memory interface option alongside industry-standard interfaces, for standard organic substrate and advanced packaging.
